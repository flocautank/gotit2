Le DNS, l’annuaire d’Internet

Vous tapez un nom de site, mais les machines ne se parlent qu’avec des numéros. Entre les deux, il y a un annuaire que vous consultez cent fois par jour sans le savoir.

Découverte5 min3 animations

Pour joindre quelqu’un, votre téléphone a besoin d’un numéro. Pourtant vous ne le tapez jamais : vous choisissez un prénom dans vos contacts. Sur Internet, c’est pareil, et le carnet de contacts s’appelle le DNS.

Scène 1 — Un nom pour vous, un numéro pour la machine

Vous, vous retenez des noms.Celui d’un journal, d’une banque, d’une boutique.

Les machines, elles, se repèrent par des numéros.Chaque machine connectée à Internet porte une adresse numérique, l’adresse IP.

Retenir ces numéros pour chaque site ? Impossible.Il y en a des centaines de millions, et ils peuvent changer.

Il faut donc un annuaire qui fait le lien.Vous donnez le nom, il rend le numéro. Cet annuaire s’appelle le DNS — Domain Name System.

L’analogie

Les contacts de votre téléphone. Vous appuyez sur « Maman », jamais sur dix chiffres. Le téléphone retrouve le numéro derrière le nom, puis compose. Le DNS fait exactement cela, pour tous les sites du monde.

Qui répond à la question ?

Il n’existe pas un immense fichier unique : l’annuaire est réparti sur de nombreux serveurs, qui se renvoient la question de l’un à l’autre.

Scène 2 — Le trajet d’une question

Vous tapez un nom dans le navigateur.Votre appareil ne connaît pas la réponse : il doit la demander.

Il pose la question à un serveur intermédiaire.Celui de votre fournisseur d’accès, en général. Son métier : aller chercher la réponse.

Celui-ci interroge d’abord un annuaire général.Il ne donne pas l’adresse du site, mais indique qui s’occupe de chaque fin de nom : .fr, .com, etc.

Puis l’annuaire de la fin du nom.Lui sait quel serveur détient les informations de ce site précis.

Enfin l’annuaire du site répond avec le numéro.Le serveur intermédiaire vous le transmet : votre navigateur peut maintenant contacter le site.

La mémoire qui accélère tout

Refaire ce voyage à chaque clic serait lent. Le DNS garde donc les réponses en mémoire, un temps limité.

Scène 3 — Se souvenir, mais pas trop longtemps

La première fois, la question fait tout le voyage.Passer par plusieurs annuaires prend un instant.

Ensuite, la réponse est gardée en mémoire.Appareil, box, serveur intermédiaire : chacun peut la conserver, et répond sans rien redemander.

Mais si un site change de serveur, l’ancien numéro traîne encore.Chaque réponse est gardée pour une durée que fixe le propriétaire du site.

Les mémoires se vident les unes après les autres.D’où le délai parfois évoqué après un changement de site : le monde n’est pas prévenu en même temps.

À retenir

  • Le DNS est l’annuaire qui traduit un nom de site en adresse numérique (adresse IP).
  • Il est réparti : la question passe de serveur en serveur jusqu’à celui qui connaît la réponse.
  • Les réponses sont gardées en mémoire (cache) pour aller plus vite.
  • Quand ce service est en panne, les sites existent toujours — mais on ne sait plus les trouver par leur nom.
La suite
