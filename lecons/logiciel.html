Informatique/Le logiciel/De quoi est fait un programme

Logiciel, système, application

Un logiciel n’est pas un objet : c’est un texte. Un texte si précis qu’une machine peut l’exécuter sans jamais se demander ce qu’il veut dire.

Découverte6 min3 animations

Le matériel, c’est ce qu’on peut faire tomber par terre. Le logiciel, c’est tout le reste : des instructions écrites, rangées dans des fichiers, que la machine déroule une par une.

Scène 1 — Du texte au programme

Tout commence par du texte.Une personne écrit des instructions dans un langage — très proche du français, en réalité : « si…, alors…, sinon… ». C’est le code source.

Ce texte est traduit pour la machine.Le processeur ne comprend que des opérations élémentaires. Un outil fait la traduction, une fois pour toutes ou à la volée.

La machine exécute, ligne après ligne.Elle ne comprend rien à ce qu’elle fait : elle suit. C’est pourquoi une consigne mal écrite produit un résultat absurde sans que personne ne s’en aperçoive.

Un logiciel n’est donc pas une chose, mais une recette.Copier un logiciel ne coûte rien. Le corriger, c’est corriger un texte — ce qui explique qu’une mise à jour se télécharge en quelques secondes.

Les trois couches

Scène 2 — Qui s’occupe de quoi

En bas, le matériel.Il ne sait rien faire tout seul : sans logiciel, un ordinateur est un presse-papier.

Au milieu, le système d’exploitation.Windows, macOS, Android… C’est le chef d’orchestre : il partage le processeur entre les applications, gère la mémoire, les fichiers, l’écran, le réseau.

En haut, les applications.Ce sont elles que vous ouvrez. Chacune demande des services au système : « affiche cette fenêtre », « ouvre ce fichier ».

Et c’est pour ça qu’un logiciel n’est pas universel.Une application écrite pour Windows parle à Windows. Sur macOS, l’interlocuteur n’est pas le même — il faut une autre version.

L’analogie

Le matériel, c’est le bâtiment. Le système d’exploitation, c’est le gardien qui distribue les clés, l’électricité et les salles. Les applications sont les occupants : ils ne touchent jamais au compteur électrique, ils demandent au gardien.

Installé ou dans le navigateur ?

Scène 3 — Deux façons d’utiliser un logiciel

L’application installée vit chez vous.Elle occupe de la place sur le disque, tourne avec votre processeur, et fonctionne sans connexion.

L’application web vit ailleurs.Votre navigateur n’affiche qu’une fenêtre : le vrai travail se fait sur un serveur. Rien à installer, rien à mettre à jour — mais rien sans réseau non plus.

C’est le même logiciel, à un endroit différent.Une messagerie, un tableur, un outil de gestion existent souvent dans les deux formes. La question n’est pas « lequel est moderne », mais « où voulez-vous que ça s’exécute ».

Le vocabulaire, en une ligne chacun

Les mots du logiciel

  • Code source — le texte écrit par un humain.
  • Programme — ce texte, traduit pour la machine.
  • Bug — une instruction qui ne dit pas ce qu’on croyait.
  • Mise à jour — une nouvelle version du texte.

Les mots de l’usage

  • Application — un logiciel destiné à un usage précis.
  • Système d’exploitation — celui qui gère la machine.
  • Navigateur — l’application qui affiche le web.
  • SaaS — un logiciel loué, exécuté chez l’éditeur.

À retenir

  • Un logiciel est du texte : des instructions, traduites puis exécutées.
  • La machine ne comprend pas ce qu’elle fait, elle suit.
  • Trois couches : matériel → système → applications, chacune s’appuyant sur celle du dessous.
  • Un logiciel peut s’exécuter chez vous ou sur un serveur : c’est toute la différence entre une application installée et une application web.
