La double authentification, pourquoi un mot de passe seul ne suffit plus

Quelqu’un qui connaît votre mot de passe peut entrer chez vous, depuis l’autre bout du monde. Un second justificatif, lui, reste dans votre poche.

Découverte5 min2 animations

Pour entrer dans votre immeuble, vous avez un code d’entrée. Mais si un voisin le surprend par-dessus votre épaule, il entre à son tour. Maintenant, imaginez qu’il faille en plus montrer votre badge : connaître le code ne suffit plus. C’est le principe de la double authentification.

Scène 1 — Un seul verrou, ou deux

Un mot de passe garde votre compte.Tant que personne d’autre ne le connaît, tout va bien.

Mais il peut être volé.Faux message, site piégé, fuite chez un service : l’intrus l’a, et il entre comme vous.

On ajoute une seconde preuve.Une chose que seul vous avez, en plus de ce que vous savez.

Le mot de passe seul ne suffit plus.C’est la double authentification, ou MFA : l’intrus s’arrête à la deuxième porte.

L’analogie

La carte bancaire. Avoir la carte ne suffit pas, il faut aussi le code ; connaître le code ne suffit pas, il faut aussi la carte. Un voleur qui n’a que l’un des deux repart bredouille.

Trois familles de preuves

On distingue ce que l’on sait, ce que l’on possède et ce que l’on est. La double authentification combine deux familles différentes : deux mots de passe, ce serait encore deux choses que l’on sait.

Scène 2 — Le code qui arrive sur le téléphone

Vous vous connectez comme d’habitude.Premier verrou : votre mot de passe.

Le service vérifie, mais ne vous laisse pas encore entrer.Il demande une seconde preuve.

Un code arrive sur votre téléphone.Il ne sert qu’une fois et expire en quelques dizaines de secondes. Une application dédiée peut aussi le produire.

Vous le saisissez.Seul celui qui a le téléphone en main pouvait le lire.

L’accès s’ouvre.Le mot de passe volé ne sert plus à rien sans ce téléphone.

Ce que ça protège, et ce que ça ne protège pas

Cela bloque la grande majorité des intrusions faites avec un mot de passe volé. Ce n’est pas infaillible : un faux site peut vous faire saisir le code en direct, et un code envoyé par SMS est moins solide qu’une application ou qu’une clé physique. Ne communiquez donc jamais un code reçu, même à quelqu’un qui se dit du support.

À retenir

  • La double authentification (MFA) demande deux preuves de familles différentes.
  • Les familles : ce que l’on sait, ce que l’on possède, ce que l’on est.
  • Un mot de passe volé ne suffit plus : l’intrus lui manque la seconde preuve.
  • Un code reçu ne se donne à personne.
