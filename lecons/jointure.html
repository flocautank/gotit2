La jointure, relier deux tableaux par une colonne commune

Un tableau pour les clients, un autre pour les commandes. Pour savoir qui a acheté quoi, il faut les rapprocher : c’est tout le métier de la jointure.

Découverte5 min2 animations

Dans un carnet d’adresses, vous n’écrivez pas toute la fiche de votre cousin à chaque fois qu’il vous envoie une carte postale : vous notez « carte de Paul » et vous retrouvez Paul dans le carnet. Les bases de données font pareil, et le geste qui retrouve Paul s’appelle une jointure.

Scène 1 — Un sujet, un tableau

Chaque sujet a son tableau.Ici, les clients : un numéro et un nom par ligne.

Les commandes ont le leur.Chaque ligne dit ce qui a été acheté, et par qui.

Le « par qui » est un simple numéro.La commande ne recopie pas le nom : elle note le numéro du client. C’est la colonne commune.

Pourquoi ne pas tout mélanger ?Si Paul change de nom, une seule ligne à corriger, et non cinquante commandes.

L’analogie

Le carnet d’adresses et la pile de cartes postales. Chaque carte porte seulement le prénom de l’expéditeur ; pour avoir son adresse complète, vous ouvrez le carnet à la bonne page. Rapprocher les deux, c’est faire une jointure.

Rapprocher les lignes

Les deux tableaux sont séparés pour de bonnes raisons. Mais pour répondre à une question comme « qui a acheté un vélo ? », il faut les remettre côte à côte.

Scène 2 — Faire correspondre

D’un côté les clients, de l’autre les commandes.Chacun garde son numéro.

Le casque porte le n° 1.La base cherche le client n° 1 : c’est Paul, les deux lignes sont reliées.

Le vélo porte le n° 2.Même geste : c’est Léa.

Le sac porte le n° 9.Aucun client n’a ce numéro : la ligne ne trouve pas son pendant.

Le résultat est un tableau reconstitué.« Paul : casque, Léa : vélo ». C’est la jointure ; le sac orphelin signale une donnée à corriger.

Quand ça se passe mal

Une jointure ne devine rien : elle compare des valeurs à l’identique. Un numéro mal saisi, un client supprimé, ou deux écritures du même numéro, et des lignes se perdent ou se dupliquent. C’est une cause classique de chiffres qui ne collent pas d’un tableau de bord à l’autre.

À retenir

  • Une base range chaque sujet dans son propre tableau, pour ne rien recopier.
  • Deux tableaux sont reliés par une colonne commune, souvent un numéro.
  • La jointure rapproche les lignes qui portent la même valeur.
  • Une valeur absente ou fautive d’un côté laisse une ligne orpheline.
