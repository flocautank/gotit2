C’est quoi une API ?

Deux logiciels qui ne se connaissent pas doivent échanger. Ils ne vont pas se promener dans les fichiers l’un de l’autre : l’un ouvre un guichet, avec une liste précise de demandes possibles. Ce guichet, c’est une API.

Découverte6 min3 animations

API veut dire « interface de programmation ». Retenez le premier mot : une interface, c’est-à-dire une surface de contact. Ce que vous voyez d’un restaurant depuis votre table, ce n’est pas la cuisine : c’est le menu et le serveur.

Scène 1 — Le problème

Deux logiciels, deux mondes.Votre site encaisse les commandes. Le transporteur, lui, suit les colis. Chacun a sa base, son équipe, son entreprise.

Et pourtant il faut bien qu’ils se parlent.« Où en est le colis 412 ? » La mauvaise réponse serait de donner à l’un un accès direct à la base de l’autre : dangereux, et cassé au premier changement.

D’où le guichet.Le transporteur publie une liste de demandes qu’il accepte, et la forme exacte de ses réponses. Personne n’entre chez personne.

C’est tout ce qu’est une API.Un contrat : voilà ce que vous pouvez me demander, voilà ce que je réponds. Ce qui se passe derrière ne regarde que celui qui l’a construit.

L’analogie

Le restaurant. Vous ne choisissez pas vos ingrédients dans le frigo : vous lisez le menu (la liste des demandes possibles), vous commandez auprès du serveur (l’API), et la cuisine reste invisible. Le chef peut changer de fournisseur ou refaire sa cuisine : tant que le menu ne change pas, vous ne voyez rien.

À quoi ressemble une demande

Scène 2 — Une demande, une réponse

Une demande tient en une ligne.Un verbe (donne, crée, modifie, supprime) et une adresse. Ici : « donne-moi le colis 412 ».

Avec une clé, presque toujours.C’est le badge d’entrée : elle identifie qui demande, et détermine ce à quoi il a droit. Une clé qui fuite, c’est une porte ouverte — d’où les précautions autour.

La réponse arrive dans une forme fixe.Toujours les mêmes champs, au même endroit. C’est ce qui permet à un programme de la lire sans se tromper — le format le plus courant s’appelle JSON.

Une API ne renvoie pas une page web.Pas de mise en forme, pas de bouton : juste de l’information brute. C’est le programme qui reçoit qui décidera de l’afficher — ou d’en faire tout autre chose.

Pourquoi tout le monde en parle

Scène 3 — Un guichet, beaucoup de clients

Le site interroge l’API.La logique métier — les prix, les règles, les stocks — n’est écrite qu’une seule fois, derrière le guichet.

L’application mobile aussi.Elle ne réimplémente rien : même guichet, mêmes réponses, même vérité.

Et les partenaires extérieurs.C’est ainsi qu’un comparateur affiche vos disponibilités, ou qu’un logiciel de caisse envoie ses ventes à votre compta.

Et désormais, les assistants IA.C’est exactement ce que fait un serveur MCP : il traduit vos API dans une langue qu’un assistant comprend. Sans API, une IA n’a rien à quoi se brancher.

Le vocabulaire, en une ligne chacun

Les mots du guichet

  • Endpoint — une adresse précise du menu.
  • REST — la façon la plus répandue d’organiser ce menu.
  • JSON — le format des réponses.
  • Clé d’API / token — le badge d’entrée.

Ce qu’on entend en réunion

  • Webhook — l’inverse : c’est l’API qui vous prévient quand il se passe quelque chose.
  • Rate limit — le nombre de demandes autorisées par minute.
  • Documentation — le menu écrit. Une API sans doc est inutilisable.
  • Versioning — faire évoluer le menu sans casser les clients existants.
Le malentendu courant

« Il suffit de brancher l’API. » Techniquement, oui. Mais une API expose ce que l’éditeur a bien voulu exposer : si la donnée qui vous intéresse n’est pas au menu, aucune intégration ne la fera apparaître. La vraie question d’un projet n’est jamais « y a-t-il une API ? », c’est « que permet-elle exactement ? ».

À retenir

  • Une API est un guichet : une liste de demandes possibles et de réponses garanties.
  • Elle évite que les logiciels aillent fouiller chez les autres.
  • Elle renvoie de l’information brute, pas une page web.
  • Un même guichet sert le site, le mobile, les partenaires — et les assistants IA.
