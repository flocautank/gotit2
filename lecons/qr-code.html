Le QR code, un message écrit en petits carrés

Un QR code ressemble à du bruit. C’est pourtant un message écrit avec deux seules « lettres » : une case noire et une case blanche. Il suffit de savoir les lire.

Découverte5 min2 animations

Un code-barres de supermarché range un numéro dans des traits. Le QR code fait la même chose en deux dimensions : il range un petit message dans une grille de cases, et tient donc beaucoup plus de choses dans le même espace.

Scène 1 — Une grille qui porte un message

Une grille de petites cases.Chaque case est noire ou blanche, rien d’autre. Mais assez de cases, bien placées, peuvent écrire un message.

Trois grands carrés servent de repères.Ils disent à l’appareil photo où est le code, de quel côté il est tourné et quelle est sa taille. On peut donc le lire de travers.

Les autres cases écrivent le message.Une case noire vaut 1, une case blanche vaut 0. Lues dans l’ordre, elles forment une suite de 0 et de 1, le binaire.

Cette suite se traduit en texte.Le plus souvent, c’est une adresse web ; ce peut aussi être un numéro de téléphone ou un simple texte.

L’analogie

Pensez à un message en morse : deux signes seulement, mais une suite assez longue dit n’importe quelle phrase. Le QR code est du morse en carrés, que l’appareil photo lit d’un coup d’œil au lieu de l’oreille.

Pourquoi ça marche même abîmé

Un code collé sur un mur finit taché, déchiré, rayé. Ceux qui l’ont conçu l’ont prévu : au moment de la création, on ajoute des cases de redondance, calculées à partir du message.

Scène 2 — Abîmé, mais lisible

Un code complet.Il contient le message, et un peu plus que le message.

Une tache en cache une partie.Une partie des cases est devenue illisible : la lecture directe est incomplète.

Les cases de secours comblent le trou.Le lecteur les utilise pour retrouver ce qui manque, un peu comme on devine un mot dont une lettre est effacée. C’est la correction d’erreurs.

Reste une précaution.Le code lit juste ce qui est écrit, sans juger. Il peut mener vers un faux site : regardez l’adresse affichée avant d’ouvrir.

Une limite à connaître

Les secours ont une capacité limitée : trop abîmé, le code devient illisible. Et rien n’empêche quelqu’un de coller son propre code par-dessus celui d’un restaurant ou d’un parking. C’est une forme de hameçonnage : la même vigilance s’applique qu’avec un lien reçu par message.

À retenir

  • Un QR code est une grille de cases noires et blanches : des 0 et des 1 qui se traduisent en texte.
  • Les trois grands carrés des coins servent de repères : le code se lit sous n’importe quel angle.
  • Des cases de redondance permettent de lire un code partiellement abîmé.
  • Le code ne prouve rien : vérifiez l’adresse avant d’ouvrir.
