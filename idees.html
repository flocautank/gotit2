Vos idées.

Ce site existe pour rendre des choses compliquées évidentes. Vous êtes donc le mieux placé pour dire ce qui manque : un mot jamais expliqué, une page qui s’affiche mal, une idée pour que ce soit plus clair.

Un concept à expliquerUn mot entendu en réunion, un sujet qui vous échappe. C’est la demande la plus utile.
Une idée pour le siteUne gêne, un manque, une fonction qui vous rendrait service.
Un bugUne animation figée, un texte qui déborde, un lien mort.

Où va votre message

Ce site est une simple page, sans serveur derrière : il ne peut rien enregistrer tout seul sans y cacher un mot de passe — ce qui serait un mot de passe public, donc un mot de passe perdu. Votre message part donc dans les issues du dépôt GitHub du site, là où tout est relu. Le bouton Envoyer via GitHub ouvre une issue déjà remplie ; il demande un compte GitHub, gratuit. Sans compte, le bouton Copier le texte met tout dans votre presse-papier, à coller dans un message ou un mail.
